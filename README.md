# DataV-Vue3-App 大屏可视化框架模板

## 安装pnpm（若未安装pnpm）

1. 通用安装方式（推荐）
```bash
# 用 npm 安装
npm install -g pnpm

# 或用 yarn 安装
yarn global add pnpm
```

2. 独立安装脚本（更纯净，推荐用于生产环境）
```bash
# Windows（PowerShell）
iwr https://get.pnpm.io/install.ps1 -useb | iex

# macOS/Linux（bash/zsh）
curl -fsSL https://get.pnpm.io/install.sh | sh -
```

3. 验证安装
```bash
pnpm -v
```
